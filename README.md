# 仰晨工具集

一组在浏览器里直接运行的小工具集合。

不依赖后端、不需要构建，每个页面都是一个可以独立打开的 HTML 文件——用即走，改即生效。

## 内容

工具按用途分门别类，覆盖开发辅助、文本与格式转换、编码与安全、图像与文件处理、生活计算，以及纯粹图一乐的实验性页面和特效演示。

首页 [`index.html`](index.html) 是所有入口的汇总，支持中文与拼音搜索（电脑端）。

## 使用

直接用浏览器打开 `index.html`，或打开任意工具自己的 `index.html`。

部署时把整个目录作为静态站点托管即可。

## 约定

- 每个工具尽量自包含，一个目录对应一件事。
- 工具之间尽量不共享代码：宁可复制多份，也不要让改一个工具波及另一个工具。
- 优先使用语义化 HTML、原生 CSS 和浏览器 API，不引入框架。
- 保持"双击 HTML 就能跑"的工作方式。
