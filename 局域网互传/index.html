连不上怎么办？
  1. 自动发现不到设备：确认两边页面顶部都显示“自动发现已开启”、两边“房间”一致；部分公司 / 校园网或代理会挡住公共 MQTT 服务，此时用这里的连接码即可（连接码和传输本身都不需要外网）。
  2. 两台设备要在同一个 Wi-Fi / 同一个局域网，路由器不要开“AP 隔离”。
  3. 两边都用系统自带浏览器或 Chrome / Edge，不要用微信等 App 内置浏览器。
  4. 关闭 VPN 再试。
  5. 仍然失败：在 Chrome 地址栏打开 chrome://flags/#enable-webrtc-hide-local-ips-with-mdns ，改为 Disabled 后重启浏览器，两边都改。
