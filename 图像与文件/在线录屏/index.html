说明：录屏使用浏览器原生的 getDisplayMedia + MediaRecorder，视频不上传任何服务器。 MP4 需要较新的 Chrome / Edge / Safari，不支持的浏览器会自动回退到 WebM（体积更小，但部分剪辑软件与微信需要转码）。 录制时浏览器顶部会一直显示「正在共享」的提示条，这是浏览器的安全机制，无法隐藏。 录完可以在结果卡片上剪辑（掐头去尾）后重新导出，也可以导出为动画 WebP 动图（无音频，Chrome / Edge / Firefox 可看，Safari 与微信可能不支持）。 如果直接用 file:// 打开时摄像头或麦克风无法授权，请改用 http://localhost 或部署到 HTTPS 后访问。
