白板使用说明

绘图

  • 铅笔 / 橡皮擦：按住拖动绘制，粗细 1 ~ 100px。橡皮擦是真正擦成透明，不是盖白色；光标圈带黑色描边，白色笔在白底上也看得见落点。
  • 直线 / 矩形 / 椭圆：按住拖动生成形状；椭圆以起点为圆心。
  • Shift：直线吸附 45° 角；矩形变正方形；椭圆变正圆。
  • 羽化：让笔画边缘变柔和（软笔刷），0% 为硬边；用顶部滑块或 Alt + 右键上下拖动调整。
  • 文本：单击空白处直接输入，Enter 换行，Ctrl+Enter 或 Esc 结束；单击已有文字进入编辑，拖动移动位置，拖四角控制点按比例缩放字号。

H打开或关闭本说明

界面

  • 顶部是悬浮胶囊，放颜色、粗细、透明度、撤销、保存和视图控制；鼠标移上去看提示。
  • 左侧竖排胶囊是绘图工具；顶部胶囊最左侧按钮可以收起 / 展开它（会记住上次状态）。
  • 矩形选中时顶部多出圆角，文本选中时多出字号。

画布

  • 整块窗口都是画布，任何位置都能画，不需要滚动。
  • 滚轮：以光标为中心缩放（5% ~ 1600%）；放大后超出窗口的部分直接不显示（窗口裁剪），缩小后画布依旧铺满窗口。
  • 空格 + 拖动 或 中键拖动：平移视图（放大后用它查看被裁掉的部分）；拖动时优先保证跟手，松手后补齐边缘内容。
  • 适应内容：把全部有内容的区域缩放到未被顶部 / 左侧胶囊遮挡的窗口区域内并居中，四周保留边距；重置视图：回到 100% 和原点。
  • 保存图片：导出全部内容为 PNG，白色背景，包含文字。
  • 画布有内容时，关闭或刷新页面会先弹确认，避免误关丢图；清空后不再提醒。
