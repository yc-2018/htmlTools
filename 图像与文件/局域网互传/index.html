连不上怎么办？
  1. 自动发现按公网出口 IP 判断局域网：只有同一个路由器（同一个公网出口）下的设备才会互相出现；不同网络即使房间名相同也不会出现。判断依赖 STUN，公司 / 校园网封 UDP 时可能判断失败，顶部会显示“无法判断所在局域网”，此时用扫码 / 连接码配对即可。
  2. 宿舍 / 运营商大内网（CGNAT）可能让出口相同的陌生人互相看到；默认房间 lan 也是公开的，建议点顶部“房间”改成自己的名字（两边一致）。
  3. 自动发现不到设备：确认两边页面顶部都显示“同局域网发现已开启”、两边“房间”一致；部分网络会挡住公共 MQTT 服务，此时用这里的连接码即可（连接码和传输本身都不需要外网）。
  4. 两台设备要在同一个 Wi-Fi / 同一个局域网，路由器不要开“AP 隔离”。
  5. 两边都用系统自带浏览器或 Chrome / Edge，不要用微信等 App 内置浏览器。
  6. 关闭 VPN 再试。
  7. 仍然失败：在 Chrome 地址栏打开 chrome://flags/#enable-webrtc-hide-local-ips-with-mdns ，改为 Disabled 后重启浏览器，两边都改。
