怎么用

  1. 先在左侧把性别、身高、体重（必要时三围）调成自己的，模型会跟着变形。
  2. 需要看手指、脚趾这类小部位时，用右上角「聚焦」跳过去，再滚轮放大；手机上用双指捏合缩放、双指同向拖动平移。
  3. 「标注」模式下点击体表打点；鼠标悬停时上方会先显示该处的中文部位名。
  4. 点开右侧列表里的某条标注，可以改症状类型、程度、范围、起始时间和补充说明；描述文字也能直接改写。
  5. 最后用「生成图文报告」导出一张 PNG：含四向全身图、每处标注的特写与清单。

总结与导出

体型与标注会自动存在本机浏览器里，下次打开还在。导出的 JSON 可以换设备继续用。

本工具只是帮你把「哪里不舒服」说清楚：人体模型是按参数近似生成的，部位名称为通俗解剖描述， 不代表真实解剖精度，也不构成任何医疗诊断或建议。身体不适请及时就医。所有数据只保存在你自己的浏览器中。
